### Overview & Role

At **PT Bank Central Asia, Tbk (BCA)**, Indonesia's largest private bank, I worked as a **Quality Assurance Automation Engineer**. My role focused on automating regression tests for web and mobile banking apps, testing critical customer journeys (such as transfers and account verification), and working closely with developers to find and fix defects before releases.

---

### Key Work & Responsibilities

#### 1. Web & Mobile UI Test Automation
* Built modular test automation suites using **Java**, **Selenium WebDriver**, and **Appium**.
* Applied the **Page Object Model (POM)** pattern so that UI locator changes in the banking app only required updating one file rather than breaking multiple test scripts.
* Automated end-to-end customer flows, including login, multi-factor authentication (MFA), fund transfers, and bill payments.

#### 2. Test Planning & BDD Testing
* Wrote test scenarios using **Cucumber BDD** syntax so business analysts, QA analysts, and developers had a shared understanding of feature requirements.
* Created test plans and regression checklists for scheduled release cycles across staging and UAT environments.

#### 3. Defect Triaging & Tracking
* Investigated test failures, captured error logs and screenshots, and filed clear defect reports in **Jira** with reproduction steps.
* Worked daily with backend developers and QA leads to prioritize and retest bug fixes before production deployment.
