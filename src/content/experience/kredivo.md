### Overview & Role

At **Kredivo Group (PT FinAccel Teknologi Indonesia)**, I work as a **Software Engineer in Test (SEIT)**. My primary responsibilities include building API and mobile automation frameworks, creating internal tools for developer productivity, and stabilizing CI/CD test pipelines for core transaction and credit services.

---

### Key Work & Responsibilities

#### 1. High-Concurrency API & Regression Testing
* Built robust API regression test suites using **Java**, **TestNG**, and **REST Assured**.
* Implemented direct database state validations in **PostgreSQL** and **MySQL** to ensure transaction balances and order lifecycles remain consistent.
* Collaborated with backend engineers to align automated test strategies with complex architecture updates.

#### 2. Internal Developer Tooling (Slack Automation Ecosystem)
* Architected and deployed an internal Slack automation ecosystem using **Slack Socket Mode**, Node.js backend, and frontend modals.
* Developed and published custom **Java JAR libraries** containing shared test triggers, reporting listeners, and notification decorators.
* Streamlined test trigger workflows, enabling developers and QA analysts to trigger targeted test runs and receive real-time execution feedback directly in Slack.

#### 3. Test Pipeline Stability & Flakiness Debugging
* Stabilized flaky test execution by actively debugging sequential test flows, transactional mock states, and staging environment configurations.
* Built mock services to simulate payment gateway scenarios and asynchronous callbacks without relying on external sandbox dependencies.
* Replaced static delays with condition-based auto-waiting to boost test pipeline reliability.

#### 4. Mobile Test Automation
* Scaled cross-platform mobile automated test execution across diverse Android and iOS device matrixes using **Appium** and **BrowserStack**.
* Optimized test suites to validate critical mobile customer journeys.

#### 5. CI/CD & Test Observability
* Centralized test execution observability by configuring **Allure Report** across CI/CD pipeline stages.
* Provided immediate failure triaging and detailed error reports for engineering teams.
